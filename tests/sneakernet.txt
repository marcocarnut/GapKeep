# Sneakernet (apps/sneakernet), from the keyboard only: the menu, how to
# play, a mistyped level code refused, then level 1 of the code 0800-21YS
# played to the end (all three shares, then the vault), the next level, a

# level everywhere. The radio is over 50 s behind the first route even at
# 0.6 s a move. Timing doesn't matter to the rest: the access point's own
# tile is always in radio, and 0800-0QV2 is lost at 7.8 s without a move.
