# Needs a test build (make TEST=1) and the test SD card (tests/sdcard).
# Needs a simulated DigiMacro: tests/digimacro/run_softusb.sh starts one
# (simavr-softusb's bridge, the real firmware 18 on a simulated Digispark,
# served over USB/IP), runs this with GK_TEST_USBIP and GK_TEST_PAD, then
# checks with tests/digimacro/check_board.py that the board types what was
# written: a TOTP code included, for the time this set on its clock.
#
# The DigiMacro app (apps/digimacro), from the keyboard alone: the gate (the
# pad held), the board's clock refused while GapKeep's is not set, the
# hardened-mode checklist, a macro written, a TOTP key imported from a QR
# code and put in a macro, the clock set after a confirmation, a password
# and the lockout, then unplugged and plugged in again through the password.
