# Needs a test build, and the rig with a Pi Camera Module v2.1 (docs/RIG.md).
# Rig only: tools/run_tests.sh and tools/run_sim_tests.sh skip scenarios
# with this line (neither QEMU nor the simulator has a Pi Camera).
# A colour QR code on a screen in the camera's view, read by the Color QR
# app through the real camera (experimental): whether its colour layer is
# read is logged, not checked (the code shown is up to whoever runs it), and
# raw frames are kept for tuning the decoder. Both of the scanner's modes.
expect Keyboard attached 60
expect launcher ready 60
send #experimental on
expect experimental features on 5
send #camera pi
expect picamera: IMX219 found \(model 0219\) 10
expect camera: pi 5
tile hello
wait 2
key meta_l
expect launcher ready: .*colorqr 10
tile colorqr
expect colorqr ready
expect picamera: streaming 1280x960 10
wait 8
serialraw 01-detail
serialshot 01-detail
wait 3
key meta_l
expect launcher ready
send #camera mode full
expect pi mode full 5
tile colorqr
expect colorqr ready
expect picamera: streaming 1640x1232 RAW8 \(full\) 10
wait 8
serialraw 02-full
serialshot 02-full
wait 1
send #camera mode auto
key meta_l
expect picamera: stopped: \d+ frames started 10
