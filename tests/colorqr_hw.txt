# Needs a test build. The experimental colour QR layer on the real Pi
# Zero, for its timing: tests/colorqr.txt as the rig can play it
# Rig only: tools/run_tests.sh and tools/run_sim_tests.sh skip it.
# (its card has no zerogap.txt, so experimental features are turned on over
# the serial line, and the launcher started again to list Color QR). The
# synthetic camera shows the test pictures built into test kernels.
expect Keyboard attached 60
expect launcher ready 60
send #experimental on
expect experimental features on 5
tile hello
wait 2
key meta_l
expect launcher ready: .*colorqr 10
tile colorqr
expect colorqr ready
camera picture colorqr/v10_a450_3_4.png
expect colorqr: code 1, \d+ bytes 20
expect colorqr: colour layer of code 1, 466 bytes, sha256 dcc98d1b7a033f23 30
serialshot 01-v10
# the screenshot used the serial line: let it settle before the next command
wait 1
camera picture colorqr/v5_a450_3_4.png
