# Needs a test build (make TEST=1) and the test SD card (tests/sdcard).
# Suites and data files (docs/APPS.md, "Suites" and "Data files"), from the
# keyboard alone: the test suite (apps/testsuite) is one tile; Enter opens
# it, Escape, Backspace or its Back button leave it. Its apps read the
# card's data/testdata with gk:data: a binary and a text file, the folder's
# hash, and what must be refused.

mark
